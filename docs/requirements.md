# 奄美大島旅行しおりアプリケーション 要件定義書（たたき台）

## 1. プロジェクト概要

### 1.1 目的
奄美大島旅行のしおり機能を提供するWebアプリケーションを開発する。参加メンバー間で旅行工程の進捗を共有し、GoogleMapを用いた案内機能を実装する。

### 1.2 対象ユーザー
- 奄美大島旅行の参加メンバー（8名）
- 主な利用環境：スマートフォン、タブレット、PC

### 1.3 技術スタック
- **フロントエンド**: JavaScript（バニラJSまたはモダンフレームワーク検討）
- **バックエンド**: Vercel（Serverless Functions使用を想定）
- **データ保存**: Vercel内でのデータ保持（データベース不使用）
  - オプション：Vercel KV（Redis互換）、Local Storage、Session Storage、Serverless Functionsでのファイル保存
- **地図機能**: Google Maps JavaScript API
- **デプロイ**: Vercel

## 2. 機能要件

### 2.1 トップページ

#### 2.1.1 表示内容
- **しおりの目的**
  - 旅行の目的を表示
  - 簡潔に旅行の趣旨を記載
- **旅行工程の進捗状況**
  - 全体の進捗率を視覚的に表示（プログレスバー）
  - 完了項目数 / 全項目数を表示
  - 各日の進捗状況も表示可能
- **メニュー**
  - ナビゲーションメニューを表示
  - 各セクションへのスムーズスクロール対応

#### 2.1.2 UI要件
- レスポンシブデザイン（iPhone SE基準、スマートフォン、タブレット、PC対応）
- ダークモード/ライトモード切替機能（既存機能を継承）
- 印刷機能（既存機能を継承）

### 2.2 メニュー構成

#### 2.2.1 ツアー内容
以下の情報を表示するセクション：

1. **参加メンバー**
   - メンバー一覧を表示
   - 現在の表示内容を継承（岡部夫婦・伊藤夫婦・今井夫婦・小野夫婦、計8名）

2. **旅の目的**
   - 旅行の目的をリスト表示
   - 既存の目的リストを継承

3. **注意事項**
   - 重要な注意事項を表示
   - 警告表示（既存のスタイル継承）

4. **係り分担**
   - 各係の担当者と役割を表示
   - カード形式で表示（既存デザイン継承）
   - 係一覧：
     - 班長
     - 風紀係
     - 宴会係
     - YouTube係
     - 会計係
     - 食事係
     - お助け係
     - 副班長

#### 2.2.2 ツアー日程

1. **基本機能**
   - 日程を日付ごとに表示（11月3日、4日、5日）
   - 各日程項目にチェックボックスを配置
   - チェック状態をVercel内で保存・共有

2. **進捗共有機能**
   - **要件**: 進捗チェックされた内容を共有できるようにする
   - **実装方法（検討事項）**:
     - オプション1: Vercel KV（Redis互換）を使用してリアルタイム共有
     - オプション2: Vercel Serverless Functions + JSONファイル保存
     - オプション3: API経由での同期機能
   - **共有範囲**: 参加メンバー全員が同じ進捗状況を閲覧可能
   - **更新方式**: 
     - オプションA: リアルタイム同期（WebSocketまたはポーリング）
     - オプションB: 手動リロードで最新状態を取得

3. **各日程項目の情報**
   - 時刻
   - 活動内容
   - 備考（必要に応じて）
   - チェック状態
   - 場所情報（GoogleMap連携用の座標または住所情報）
   - **WEBサイトリンク機能**
     - 観光地や食事処の名称からWEBサイトへのリンクを表示
     - 各施設名をクリック可能なリンクとして表示
     - 外部リンクアイコンを表示（新規タブで開く）
     - リンク先URLをデータ構造に含める

4. **進捗表示**
   - 全体進捗率の表示
   - 各日の進捗率表示
   - 完了項目の視覚的フィードバック（打ち消し線、グレーアウト等）

#### 2.2.3 GoogleMap（奄美大島の地図：FromTo）

1. **基本機能**
   - 奄美大島の地図を表示
   - Google Maps JavaScript APIを使用

2. **経路案内機能（FromTo）**
   - **出発地点（From）の指定**
     - ユーザーが任意の地点を指定可能
     - 地図上でクリックして地点を指定
     - 日程項目から地点を選択可能（例：「奄美大島空港から次の目的地へ」）
   - **到着地点（To）の指定**
     - ユーザーが任意の地点を指定可能
     - 日程項目から目的地を選択可能
   - **経路表示**
     - From地点からTo地点までの経路を表示
     - 徒歩、車、公共交通機関の経路を選択可能（オプション）
     - 距離と所要時間を表示
   - **日程連携**
     - ツアー日程の各項目から、その場所の地図表示に遷移可能
     - 日程項目から直接経路検索を開始できる機能

3. **マーカー表示**
   - 日程に含まれる主要地点にマーカーを表示
   - マーカークリックで日程情報を表示（ポップアップまたはサイドパネル）

4. **地図操作**
   - ズームイン/アウト
   - 地図のドラッグ移動
   - 現在地表示（GPS利用、オプション）

## 3. 非機能要件

### 3.1 パフォーマンス
- ページ読み込み時間: 3秒以内（通常のネットワーク環境）
- 地図表示: 2秒以内
- 進捗状態の保存/読み込み: 1秒以内

### 3.2 ユーザビリティ
- スマートフォンでの操作性を重視
- 直感的なUI/UX
- 既存のデザインスタイルを継承（色合い、レイアウト等）

### 3.3 セキュリティ
- Google Maps APIキーは環境変数で管理
- データの不正アクセス防止（必要に応じて簡易認証を検討）
- HTTPS接続を強制

### 3.4 互換性
- モダンブラウザ対応（Chrome、Safari、Firefox、Edgeの最新版）
- iOS Safari対応
- Android Chrome対応

## 4. データ構造（検討事項）

### 4.1 進捗データ
```javascript
{
  schedule: [
    {
      date: "2024-11-03",
      items: [
        {
          id: "item-1",
          time: "6:30",
          activity: "羽田第1ターミナル第3時計台に集合",
          checked: false,
          location: {
            name: "羽田空港第1ターミナル",
            lat: 35.5494,
            lng: 139.7798
          },
          website: "https://example.com" // 観光地・食事処のWEBサイトURL（オプション）
        },
        // ... 他の項目
      ]
    },
    // ... 他の日
  ],
  lastUpdated: "2024-11-03T10:30:00Z",
  version: 1
}
```

### 4.2 保存方法の検討

#### オプション1: Vercel KV（推奨）
- Redis互換のキーバリューストア
- リアルタイム更新が容易
- 費用: 無料プランあり

#### オプション2: Vercel Serverless Functions + JSON
- Serverless Functionsでファイル読み書き
- ファイルシステムまたは外部ストレージ（例：Vercel Blob）
- シンプルな実装

#### オプション3: LocalStorage + 同期API
- クライアント側でLocalStorageに保存
- 定期的にServerless Functionsに送信して同期
- オフライン対応可能
