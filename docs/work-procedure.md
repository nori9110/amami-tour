# 奄美大島旅行しおりアプリケーション 作業手順書

## 1. 概要

本ドキュメントは、プロトタイプをベースに本番アプリケーションを作成するための作業手順書です。作業は4つのフェーズに分けて実施し、各フェーズで進捗状況をチェックできるようにしています。

### 1.1 作業範囲
- プロトタイプ（`src/prototype/`）をベースに本番コードを作成
- 要件定義書、画面定義書に基づいた実装
- Vercelへのデプロイ

## 2. チェックリストの使い方

### 2.1 進捗管理方法
1. 各項目を完了したら、チェックボックスに `[x]` を付ける
2. 各フェーズの進捗率を計算する
3. 全体進捗率を計算する（各フェーズの進捗率 × フェーズの重み）

### 2.2 進捗率の計算式

```
全体進捗率 = (フェーズ1進捗率 × 0.30) + (フェーズ2進捗率 × 0.20) + 
             (フェーズ3進捗率 × 0.30) + (フェーズ4進捗率 × 0.20)
```

各フェーズの進捗率 = 完了項目数 / 全項目数 × 100

## 3. 技術的な注意事項

### 3.1 ファイル構成
```
src/
├── app/ (または production/)
│   ├── index.html
│   ├── schedule.html
│   ├── map.html
│   ├── assets/
│   │   ├── css/
│   │   │   └── styles.css
│   │   └── js/
│   │       ├── data.js
│   │       ├── main.js
│   │       └── map.js
│   └── api/ (Vercel Serverless Functions用)
│       └── sync/ (将来実装)
└── prototype/ (プロトタイプは残す)
```

### 3.2 APIキーの管理
- 開発環境: `.env.local` ファイルで管理
- 本番環境: Vercelの環境変数で管理
- **重要**: APIキーはGitにコミットしない

### 3.3 データ構造
- 日程データ: `data.js`に配置
- ローカルストレージキー: `item-{番号}`, `theme`, `tour-complete`

## 4. トラブルシューティング

### 4.1 よくある問題

| 問題 | 原因 | 解決方法 |
|------|------|---------|
| 地図が表示されない | APIキーが設定されていない | 環境変数を確認 |

| ページ遷移ができない | ファイルパスが間違っている | 相対パスを確認 |
