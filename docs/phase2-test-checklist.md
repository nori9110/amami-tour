## 前提条件

### APIキーの設定確認
- [ ] Google Maps APIキーを取得済み（`docs/google-maps-api-setup.md`を参照）
- [ ] `src/app/map.html`の`YOUR_API_KEY`を実際のAPIキーに置き換えた
- [ ] APIキーの制限設定（HTTPリファラー）に`http://localhost:*`が含まれている

**APIキー未設定の場合**: 
- 地図表示とマーカー表示は確認できません
- 経路検索機能も動作しません
- ただし、HTMLの構造、UI要素、JavaScriptのエラーは確認できます

## 5. 経路検索機能（APIキー設定後）

### 5.1 経路検索の実行
- [ ] FromとToの両方を選択して「経路検索」ボタンをクリックすると経路が表示される
- [ ] FromまたはToが未選択の場合、アラートが表示される
- [ ] 経路が地図上にポリライン（線）で表示される
- [ ] 出発地点と到着地点にマーカーが表示される（DirectionsRenderer）

### 5.2 移動手段の切り替え
- [ ] 「車」を選択して検索すると車での経路が表示される
- [ ] 「徒歩」を選択して検索すると徒歩での経路が表示される
- [ ] 「公共交通機関」を選択して検索すると公共交通機関での経路が表示される
- [ ] 各移動手段で経路が異なる（距離・所要時間が変わる）

### 5.3 経路情報の表示
- [ ] 経路検索後に「経路情報」パネルが表示される
- [ ] 距離が正しく表示される（例: "15.2 km"）
- [ ] 所要時間が正しく表示される（例: "25分"）
- [ ] 移動手段が表示される（例: "車"）
- [ ] 「Google Mapsアプリで開く」リンクが表示される

### 5.4 Google Mapsアプリリンク
- [ ] 「Google Mapsアプリで開く」リンクをクリックするとGoogle Mapsが開く
- [ ] 新規タブで開く（`target="_blank"`）
- [ ] `rel="noopener noreferrer"`が設定されている
- [ ] 正しい出発地点と到着地点の座標がリンクに含まれている
- [ ] 選択した移動手段がリンクに含まれている

### 5.5 クリア機能
- [ ] 「クリア」ボタンをクリックすると経路が消える
- [ ] 経路情報パネルが非表示になる
- [ ] 地図上のポリラインとマーカーが消える
